Quick Start

Requirements

Rust 1.78 or newer: https://rustup.rs
Make: included on Linux. On Windows: choco install make or winget install GnuWin32.Make
No other dependencies. SQLite is bundled.

Build and launch

cd F:\dev\legion
make legion

Opens http://localhost:3000 automatically. Scan root defaults to F:\dev.

Custom scan root or port

.\target\debug\legion-web.exe --scan-root C:\your\code --port 3000

All make targets

make legion         Build and launch web dashboard (port 3000)
make web            Same as make legion
make tui-launch     Build and launch TUI dashboard
make release        Build release binaries
make test           Run all tests
make clean          Clean build artifacts
make feeds          Pull CISA KEV and AbuseIPDB feeds
make scan           Scan F:\dev for CVEs
make alerts         Print active alerts
make status         Print system summary

Web API

All endpoints served from http://localhost:3000. No authentication required (local-only server).

MethodPathDescription
GET/api/statusSystem telemetry, alert counts, scan summary, feed counts
GET/api/alertsAll unacknowledged alerts
POST/api/alerts/:id/ackAcknowledge alert by ID
POST/api/scanRun package scan, AI detection, alert correlation
POST/api/feeds/refreshPull CISA KEV and AbuseIPDB concurrently
GET/api/feeds/statusFeed cache row counts
GET/api/threatsCached AI detections, OSV findings, feed counts
GET/api/wineventsLocal OS events: Windows Event Logs, Linux journald
GET/api/dockerDocker container list with status
GET/api/connectionsActive remote TCP IPs

AI Threat Intel

Legion checks for three categories of AI supply chain risk when you run a scan.

Malicious AI packages

40+ typosquatted and confirmed-malicious packages targeting OpenAI, Anthropic, LangChain, LlamaIndex, and DeepSeek users. Any match triggers a Critical alert. Examples: chatgpt, openai-python, anthropic-sdk, langchian, gpt4.

Vulnerable AI SDK versions

Known CVEs in popular AI SDKs with installed-version comparison. Key entries:

PackageFix versionAdvisory
langchain0.1.17CVE-2024-28088 RCE via PALChain
transformers4.36.0CVE-2024-3568 pickle RCE in model load
gradio4.44.0CVE-2024-47084 path traversal
llama-index-core0.10.24CVE-2024-3095 eval RCE
pyautogen0.2.0AML.T0037 unrestricted LLM code exec

Running agent process detection

Scans running processes for LangChain, AutoGen, CrewAI, LlamaIndex, DSPy, LiteLLM, Guidance, and Ollama agent signatures. Reported as Medium severity with MITRE ATLAS technique IDs.

OSV.dev integration

After each scan, Legion queries api.osv.dev/v1/querybatch for all scanned packages. Results are cached in SQLite and shown in the AI Threat Intel panel. No API key needed.

CISA KEV + AbuseIPDB

Feeds refresh via POST /api/feeds/refresh or make feeds. CISA KEV (~1500 entries) and AbuseIPDB IPs are stored locally and cross-referenced against scan results.

MITRE ATLAS IDs referenced: AML.T0012 (credential theft), AML.T0018 (model backdoor), AML.T0037 (unrestricted exec), AML.T0040 (prompt injection), AML.T0043 (data extraction)

Legion Runner

Legion Runner is the Linux-only companion for hardened ephemeral GitHub Actions runners. On Windows, manage it through WSL with a systemd-enabled distribution. The dashboard never asks for or stores GitHub runner tokens.

What it adds

ControlSecurity value
Ephemeral lifecycleOne job per runner, then teardown and workspace wipe
eBPF egress captureProcess-attributed outbound connection monitoring on Linux
Default-deny egressnftables allowlist enforcement for CI supply-chain containment
File integrityDetects tampering with source, hooks, and sensitive config files

Linux quick start

git clone https://github.com/OpenSource-For-Freedom/Legion_runner.git
cd Legion_runner
sudo ./scripts/install.sh
export LEGIONR_TOKEN=<github_pat_with_runner_admin>
sudo -u legionr -E legionr provision <owner/repo-or-org> --config /etc/legion-runner/default.json --container podman --link http://127.0.0.1:3000
sudo ./scripts/harden.sh
sudo systemctl enable --now legionr@default

Windows via WSL

wsl --install
wsl -e bash -lc "git clone https://github.com/OpenSource-For-Freedom/Legion_runner.git"
wsl -e bash -lc "cd Legion_runner && sudo ./scripts/install.sh"
Runner is intentionally Linux-only because eBPF, nftables, systemd hardening, and GitHub runner sandboxing are Linux primitives. Windows support means WSL management, not native Windows execution.

Architecture

F:\dev\legion\
├── crates/
│   ├── legion-core/      Rust library
│   │   ├── feeds.rs      Threat feed fetching and caching
│   │   ├── scanner.rs    Package lock-file parser (Cargo/npm/pip)
│   │   ├── alerts.rs     Alert engine and correlation
│   │   ├── db.rs         SQLite persistence layer
│   │   ├── telemetry.rs  System stats, Docker, WinEvents, TCP
│   │   ├── ai_detector.rs AI/agentic attack detection engine
│   │   ├── threat_intel.rs OSV.dev and CISA KEV feeds
│   │   └── quarantine.rs Package quarantine manager
│   ├── legion-cli/       CLI binary (legion)
│   ├── legion-tui/       TUI dashboard binary (legion-tui)
│   └── legion-web/       Web server binary (legion-web)
│       ├── main.rs       axum routes and handlers
│       └── dashboard.html Embedded single-file web app
├── agents/               C agent for cross-platform telemetry
└── Makefile
